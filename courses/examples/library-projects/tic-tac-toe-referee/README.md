# Tic-Tac-Toe Referee

Evaluate a board with indexed winning lines.

## What to notice

The board is checked against indexed winning lines, then classified as a win, draw, or unfinished game. Trace a diagonal win and a full board without a winner through the decision path.

## Concepts

- arrays
- Option
- patterns

## Your challenge

Detect a draw separately from an unfinished board and validate that turn counts are legal.

## Proof

Run the starter first, predict the changed output, make one focused
edit, and Run again with the bundled compiler.
