# Error Pipeline

A custom error type propagated with ?.

## What this project does

The starter is a complete Rust project. Read `src/main.rs` and its
`Cargo.toml`, then run it in Crabrix to see the result in **Output**.
All compilation and execution happen on the device.

## Concepts

- `Result`
- `From`
- `Display`

## Try it

Add a failure case and trace how its custom error reaches main through `?`.

The downloaded example stays unchanged when you open it. Crabrix saves
an editable copy in My Projects.
