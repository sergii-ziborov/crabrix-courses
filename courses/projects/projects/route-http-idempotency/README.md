# Retry Without Duplicating Tasks

Return 400 for a blank key; 200 for the same stored key and payload; 409 for the same key with another payload; 201 for a new key.

Terminal companion: Create one task twice with curl using the same Idempotency-Key header, then change the title while retaining the key.

The private verification caller is supplied by the installed lesson. SQL-profile lessons require workflow-terminal-v1; they execute real SQLite in a fresh database. The complete Task Ledger source is in the route companion files.
