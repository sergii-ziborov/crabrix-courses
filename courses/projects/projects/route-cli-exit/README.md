# Separate Output from Failure

Return stdout, stderr and exit code. Success emits COUNT followed by newline only on stdout with 0; errors emit error: MESSAGE followed by newline only on stderr with 2.

Terminal companion: Run a valid and an invalid companion CLI invocation and compare output, error stream and exit result.

The private verification caller is supplied by the installed lesson. SQL-profile lessons require workflow-terminal-v1; they execute real SQLite in a fresh database. The complete Task Ledger source is in the route companion files.
