# Bind an Artifact to Its Source

Validate lowercase hexadecimal commit(40) and digest/expected(64), then require digest==expected. This checks metadata only; actual digest computation belongs to the supplied build-byte verification step.

Terminal companion: Run the desktop delivery script, inspect its source revision and computed artifact SHA-256, then modify an artifact copy and observe verification fail.

The private verification caller is supplied by the installed lesson. SQL-profile lessons require workflow-terminal-v1; they execute real SQLite in a fresh database. The complete Task Ledger source is in the route companion files.
