# Process Bounded Standard Input

Reject input exceeding max_bytes; trim lines, omit blanks, reject titles longer than 80 Unicode scalar values, and preserve order.

Terminal companion: Create input.txt, then run cargo run -- import < input.txt; inspect stderr for an oversized record.

The private verification caller is supplied by the installed lesson. SQL-profile lessons require workflow-terminal-v1; they execute real SQLite in a fresh database. The complete Task Ledger source is in the route companion files.
