# Recover One Historical File

Return the current tree with exactly one path restored from a historical tree. Absence in history removes that path.

Terminal companion: Use git log, git show <full-commit>:src/main.rs, then git restore --source <full-commit> -- src/main.rs and inspect the preview.

The private verification caller is supplied by the installed lesson. SQL-profile lessons require workflow-terminal-v1; they execute real SQLite in a fresh database. The complete Task Ledger source is in the route companion files.
