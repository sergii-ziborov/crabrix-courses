# Encode a Valid JSON Boundary

Return a quoted JSON string; escape quote, backslash, newline, carriage return and tab, encode remaining controls below U+0020 as lowercase four-digit \u escapes, and retain other Unicode scalars.

Terminal companion: Inspect curl -i output for a title containing quotes. Compare the response Content-Length with its encoded body.

The private verification caller is supplied by the installed lesson. SQL-profile lessons require workflow-terminal-v1; they execute real SQLite in a fresh database. The complete Task Ledger source is in the route companion files.
