# Validate Before Starting the Service

Accept an ASCII-digit decimal port in 1024..=65535 and a nonempty database string without whitespace. Return port for port errors and database for database errors; validate the port first.

Terminal companion: Start cargo serve --port 8080 --database tasks.db. Refuse an invalid port, then check /health after successful startup.

The private verification caller is supplied by the installed lesson. SQL-profile lessons require workflow-terminal-v1; they execute real SQLite in a fresh database. The complete Task Ledger source is in the route companion files.
